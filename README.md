# WeatherTrak
Version: 1.0.0

## Description
Pulls the past weeks weather data from api.weather.gov. I created this for my husband who wanted weather data for his gardening.

## License Information
Do with it what you will.
   

## Usage
Run the `getweather.py` file using python 13 or later.
